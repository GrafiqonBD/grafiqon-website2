# GRAFIQON Website

A responsive B2B indenting and global sourcing website for GRAFIQON.

## Files
- `index.html` — website structure
- `style.css` — responsive styling
- `script.js` — mobile menu + inquiry email action

## Before publishing
1. Replace `your-email@example.com` in `index.html` and `script.js`.
2. Replace the placeholder phone/WhatsApp number and Dhaka address.
3. Add your final GRAFIQON logo if desired.
4. Update product/supplier information as your business develops.

## GitHub Pages deployment
1. Create a new GitHub repository, e.g. `grafiqon-website`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open the repository's Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the website and provide a `github.io` address.
7. Later, a custom domain can be connected from the same Pages settings.
